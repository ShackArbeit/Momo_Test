# 02 - Catalog and Pages

請只做這一個 phase，完成後先停下來。
開始前先確認 `01-shell-routing.md` 已完成。

## 目標
- 建立 mock data 與商品瀏覽流程。
- 讓首頁、搜尋頁、商品頁可以讀到資料。

## 請先理解
- 這一階段要把產品內容做出來，而不是先做購物車。
- mock data 要夠多，讓搜尋和列表看起來像真的商店。

## 請執行
- 建立 mock catalog data。
- 首頁顯示 momo 風格的 banner、分類或商品區塊。
- 搜尋頁可根據關鍵字篩出商品。
- 商品頁可根據 `id` 找到正確商品資訊。
- 點擊商品可進入詳情頁。
- mock data 數量請控制在 500 到 1000 筆之間。
- 不要少於 500 筆，不要超過 1000 筆。

## 交付標準
- 首頁不是只有 static text，而是有商品內容。
- 搜尋頁能顯示合理結果。
- 商品頁能正確對應 mock data。

## 輸入
- `01-shell-routing.md` 的結果
- mock catalog data 的設計方向

## 輸出
- 有內容的首頁
- 可搜尋的商品列表
- 可進入的商品詳情頁

## 禁止事項
- 先不要做購物車。
- 先不要做 telemetry。
- 不要把資料拆得太碎，避免拖慢進度。

## 完成後停止
- 這個 phase 先不做購物車。
- 先不做 telemetry。
- 不要為了資料結構做過度抽象。
- 不要跳到購物車 phase，先驗收頁面內容。
