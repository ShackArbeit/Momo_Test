# 01 - Shell and Routing

請只做這一個 phase，做到就停。
開始前先確認 `00-overview.md` 已讀完。

## 目標
- 建立 app shell、layout 與 routing。
- 先讓三個路由都能正常進入。
- 不在這個 phase 做完整資料與購物車邏輯。

## 請先理解
- 這一階段的目的只是把骨架搭起來。
- 你要先能在三個路由之間切換，再談頁面內容。

## 請執行
- 建立 `react-router-dom` 路由。
- 完成 `/`、`/search`、`/goods/:id` 的基本頁面。
- 建立共用 layout 與 header。
- 建立基本搜尋入口，讓使用者能從首頁到搜尋頁。

## 交付標準
- 三個路由都可正常切換。
- 頁面有基本版型，不是空白頁。
- layout 可以重複使用。

## 輸入
- `00-overview.md`
- 目前專案中的 app 入口與樣式

## 輸出
- 可運作的 app shell
- 可切換的三個基本路由

## 禁止事項
- 不要做完整 mock data。
- 不要做購物車。
- 不要做 telemetry。
- 不要做過度 UI 細節。

## 完成後停止
- 這個 phase 只做到可導航的 app shell。
- 不要在這裡做完整 mock data 或購物車邏輯。
- 不要直接跳到下一個 phase，先交出目前結果。
